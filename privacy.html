Privacy Policy

Last updated: October 4, 2026

Security Questionnaire Copilot is currently a skills-only ChatGPT plugin. This version does not operate a separate customer database, persistent company knowledge base, or independent user-account system.

Information handled

The plugin processes questionnaire and evidence content that the user supplies in the ChatGPT conversation. Users should not provide passwords, API keys, private keys, or unnecessary personal information.

Storage and sharing

This plugin does not claim to independently store, secure, retain, or delete uploaded company documents. It does not operate a separate analytics or advertising database in this version.

Data handling within ChatGPT is subject to the applicable OpenAI product terms and privacy policies.

Changes

If a future version adds a backend, persistent storage, analytics, or external integrations, this policy will be updated before those practices are introduced.

Contact

Questions can be raised through the public GitHub issue tracker.
